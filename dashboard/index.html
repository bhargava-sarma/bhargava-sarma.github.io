This page edits content.json in your repository through the GitHub API. It needs a token with permission to write to that one repository.

  1. Open github.com/settings/personal-access-tokens and create a fine-grained token.
  2. Repository access: only bhargava-sarma.github.io.
  3. Permissions: Contents → Read and write. Nothing else.
  4. Give it a short expiry. Paste it below.

The token stays in this tab only — it is cleared when you close it, and is never written to the repository. Anyone can open this page, but without a token it can do nothing. If you paste one on a shared machine, revoke it afterwards.
